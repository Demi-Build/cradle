Mesh-edit consequences

Every accepted operation and every re-import changes geometry, and some artifacts downstream were conditioned on the geometry that existed before. Those get flagged needs-review and stay fully usable. The list of things that never stale matters as much: the 2D anchor does not stale from mesh work, and the mesh does not stale from 2D re-anchoring.

where the flag appears
On the artifact itself — a render thumbnail, a clip row, a sprite state — as the same NR badge used everywhere else.
On the accept/import card, as a “what this will stale” block read before the write.
In History, on the op entry, with the artifact list attached.
clearing it
Re-render (free) clears render NR immediately.
Re-checking the test-pose strip clears clip NR — also free.
Only sprite regeneration costs money, and it confirms on its own button with its own estimate.
Dismiss exists: “I have looked, it is fine.” That is a judgement, and it is journaled as one.
the two independences
Mesh work never stales the 2D anchor. The anchor is the locked truth; the mesh is measured against it.
Re-anchoring never stales the mesh. Proportions survive; only drift is recomputed, and drift is information.
Holding both means a user can work in either dimension without dreading the other.
