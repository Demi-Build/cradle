Generation routing

Many doors is the goal — you should be able to make art, animation, audio or layout wherever you can see the thing it belongs to. What must not multiply is destinations: each kind of generation has exactly one place it happens, and every door routes there.

the rule

Generation is offered wherever the base thing is visible — a character, an enemy, an item, a tile, a level, a scene. The door is local; the work happens in that kind's one destination, and the estimate is on the door before you walk through it.

what this buys

Flexibility without confusion. You can ask for a song while standing in a level, or an SFX while auditioning an animation, and still only ever learn four screens. A door you have never used behaves like the one you have.

the invariants
1 · the estimate is on the door, not only in the destination
2 · a door never runs a paid job silently; it opens the destination staged
3 · results land where the thing lives, never in a downloads tray
4 · the agent uses the same destination you would
