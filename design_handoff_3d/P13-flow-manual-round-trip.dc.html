cradlekeeps it safe
Writes the GLB to a stable per-project exchange path — never a temp directory — and launches the detected Blender as an external process. Detection is the Godot pattern: $BLENDER_BIN → PATH → /Applications, pinned to 4.x LTS.
Shows a watching state on the surface: the path, elapsed time, and Cancel watch. Cradle stays fully usable meanwhile — this is not a modal, and an abandoned watch expires quietly with the file left in place.
Notices the mtime change, loads the file, and compares it against the version it exported. Nothing is written yet; a save is an offer, not an import.
Builds the re-import diff card: vertex delta, bone-name compatibility, weight sanity, UV island count, texture-map changes, and a silhouette render-diff — plus the “what this will stale” list, read before the write.
Journals an import op with before/after hashes and the source path, marks the dependent renders and clips NR, and leaves everything usable. History shows the op like any other write, with Restore beside it.
spend& failure states
freeBlender missing → the button is disabled with the reason and an install pointer. Nothing half-starts.
freeWatch abandoned → the card collapses to “export still on disk”, re-armable in one click.
unreadable fileA corrupt or non-glTF save is reported with the parser error. The current mesh is untouched.
bones renamedNamed per bone, with the count of poses and clips that would stop mapping. Import is still allowed — it is your call, made with the number in front of you.
freeImport writes a version. Discard writes nothing and keeps the file on disk in case you change your mind.
why not a Blender addon

An external process on interchange files keeps the licence boundary clean: the GPL covers Blender's code, not the files it edits. If a small “send back to cradle” addon ever ships, it is its own GPL script, separate and harmless.

same shape as Replace

Asset Replace already teaches this rhythm: incoming file, diff against the current one, journal the swap, flag downstream. Meshes reuse it with mesh-specific numbers rather than inventing a second mental model.

the three verbs hold

⌘Z undoes pre-save edits in the pose and timeline surfaces. Agent ops and re-imports are versions, undone by Restore. Nothing in this flow silently overwrites anything.
