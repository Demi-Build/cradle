guidance refused

A reference at the wrong resolution is refused before any spend, and Generate stays disabled carrying the reason: That sheet is 64×64; this character is 32×32. Downscale it or pick another reference.

no anchor locked

The modal opens in an explain state instead of a form: Lock an anchor first — every frame is generated against it, and without one the states will not look like the same character. One button, back to the character editor.

where the boundary sits

Batches, gaps and whole-character work: the composer on the character editor. One state, with guidance and a comparison: this modal. Timing, offsets and frame order: the Animation tab. Pixels: PixEd.
