Phase 2 addendum — the three-tier 3D system

Cradle does not hand-build mesh surgery tools. It establishes and judges; a Phase 1 roster specialist drives headless Blender for the operations; the user opens real Blender for the artistry. Eleven boards, both themes, same tokens and doctrine as the parent package.
