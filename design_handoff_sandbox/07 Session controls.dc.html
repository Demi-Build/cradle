what this replaces

The level editor's floating “playing… (Esc quits)” note. Same trigger, same Esc behaviour — it now names the engine, the level and the link state, and it survives navigating away from the level.

Session rules spec notes
primary engine

A project names one. Everywhere an engine is chosen — play buttons, session chips, the launch row above — the primary reads first and full-strength; the twin sits second at muted weight. It is never hidden, and switching is one click with a tooltip saying what changes.

make live

A session launched from outside cradle can be adopted: “Make live” connects the edit channel. Disabled with a reason when the session predates the channel protocol.

multiple sessions

One per engine is the common case; more is allowed. Only one session per engine can hold the live channel, and the registry says which. Applying an edit swaps into every live session that runs the affected level.

crash

The chip turns red and stays until dismissed. The popover shows the last 20 log lines with a copy button and “Relaunch”. Nothing auto-restarts — a crash loop is worse than a stopped game.
