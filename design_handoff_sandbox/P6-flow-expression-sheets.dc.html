the P1 question, answered

Moods should NOT auto-batch with animation states for every character. Generate them when the character has dialogue, or on demand — an enemy with no lines never needs six faces. P1's board shows the combined batch; this is the recommendation.

empty state

No sheet yet: the mood picker shows the full enum greyed, each with “no portrait — generate the expression sheet”, and one button that does it. The dialogue is fully authorable before any portrait exists.
