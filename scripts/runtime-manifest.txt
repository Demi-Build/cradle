# THIS FILE IS THE PIN. `scripts/fetch-runtime.sh` reads every value from
# here; nothing is buried in the script, so bumping the runtime is a diff on
# this file (plus whatever CI cache keys quote it).
#
# Grammar — one record per line, `<key> <value...>`; `#` starts a comment.
#   release       python-build-standalone release tag (a date).
#   python        CPython version inside that release.
#   canon_source  Where the canon wheel comes from. A relative path is
#                 resolved against the CRADLE REPO ROOT; anything that is not
#                 an existing path or .whl is handed to pip as a requirement
#                 source (`canon-ai[extras] @ <value>`). `CANON_SPEC` in the
#                 environment overrides it (CI sets it to its own checkout).
#   canon_ref     Which canon-ai ref CI checks out before handing the checkout
#                 to the fetch as `CANON_SPEC`. A branch, tag, or full sha.
#                 It lives HERE and not in the workflows because it is the one
#                 input that decides the app's actual behaviour, and a release
#                 tag that names a moving branch bundles whatever that branch
#                 happened to be at build time. Both workflows read this line.
#                 Bumping it also busts the runtime cache, which keys on this
#                 file's hash.
#
#                 !! RELEASE BLOCKER, 2026-09-02: `main` does NOT yet carry the
#                 September work this row's bundle needs — the `agent` and
#                 `openai` extras are absent from canon-ai's pyproject on main,
#                 and so are `canon/agent/service.py` (A2's sidecar) and
#                 `canon/packs/platformer/play.py` (the play harness). A v* tag
#                 pushed today therefore CANNOT build: `fetch-runtime.sh` fails
#                 by name at its extras precheck. Point this line at the ref
#                 that carries them (a sha is best) once it lands upstream.
#   canon_extras  The extras the BUNDLE installs. Decided 2026-09-01:
#                 `agent` is in (the agent panel is dead in a bundled app
#                 without fastapi/uvicorn) and `openai` is in (pure python,
#                 and what makes the kimi backend work). The torch extras
#                 (`huggingface`, `images-local`) stay out — gigabytes for a
#                 path the desktop app never takes.
#   sha256        <target-triple> <hex> — one line per supported platform.
#                 The triple is Rust's target triple, which is also
#                 python-build-standalone's own triple and the directory name
#                 under `src-tauri/resources/runtime/`. One vocabulary.
#
# Asset name:  cpython-<python>+<release>-<triple>-install_only.tar.gz
# Asset URL:   https://github.com/astral-sh/python-build-standalone/releases/download/<release>/<asset>
# Checksums come from that release's own SHA256SUMS asset.
