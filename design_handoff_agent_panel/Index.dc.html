Agent panel

A docked third column for Wick, the foreman agent. It reads the whole project, routes work to specialists, and asks before it changes or spends anything. Seven screens, both themes, plus the spec and the build map.

The four rules the design holds to
  1. Paid reads as paid before any confirm — price and model on the card, price in the button.
  2. Grants are per project, and every label says “in this project”.
  3. Stop always means: start nothing new, keep what landed, say what it cost.
  4. The user never picks a specialist. The run card is how routing becomes visible.
