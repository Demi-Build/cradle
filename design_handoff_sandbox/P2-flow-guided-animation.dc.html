Loads the state's frame map and stored motion spec (stride, contact frames, fps) and shows the current loop playing beside the brief field.
Composes the img2img request: locked anchor as identity, guidance images as motion, palette as constraint. The composed prompt is visible and editable.
Runs the legs in parallel where the provider allows, writing each candidate to the store as it lands. Honest progress: 2 of 3 · 31 s, cancel keeps what finished.
Runs the free checks per candidate and labels the differences it can measure: silhouette drift, palette conformance, frame-to-frame delta. No score, no ranking — the person watching the loop decides.
Keeping a candidate writes one version and updates the frame map; the discarded candidates stay in the store, reachable from History. The PixEd handoff carries the flagged frame list.

A reference at the wrong resolution is refused before spending: “That sheet is 64×64; this character is 32×32. Downscale it or pick another reference.” The Generate button stays disabled with that reason on it.
